How it works

No root. No cloud. Just your TV.

  1. 1

    Allow it once

    Turn on developer options and accept the "Allow USB debugging?" prompt on the TV. That's the only permission it needs.

  2. 2

    It swaps the home screen

    Through the TV's own ADB (localhost, nothing leaves the TV) it becomes the home screen and screensaver, and turns off the stock launcher plus a short list of promo apps. Nothing is uninstalled.

  3. 3

    Undo anytime

    One button brings back the factory home screen, screensaver and every app. If something ever goes wrong, it switches back by itself.

Install

About ten minutes, start to finish.

Free, open source and easy to undo.

  1. On the TV: In the LG Content Store, install Developer Mode. Sign in with a free LG developer account, turn on Dev Mode Status (the TV restarts), then turn on Key Server. Note the IP address and passphrase shown.
  2. On your computer: clone the repo and build:
    git clone https://github.com/fernandodimas/custom-webos && cd custom-webos && ./build.sh
  3. Install to TV: type the TV's passphrase when prompted:
    python3 webos/install.py 192.168.1.50
  4. Quick Access: while Custom webOS Home is open, hold a number key (e.g. 1) on the Magic Remote to map it to that key from anywhere.

FAQ

Good questions.

Is it safe?

Yes. It runs as a developer app through LG's Developer Mode. Nothing is rooted or uninstalled: LG's stock launcher remains untouched and available at any time.

How do I open it quickly?

While Custom webOS Home is open, press and hold any number key (like 1) on your LG Magic Remote. From then on, holding 1 opens it from any HDMI input or app.

Does it change picture quality?

No. Picture settings and picture modes are completely untouched. HDMI inputs and native apps play at full hardware resolution and HDR capability.

What happens when Developer Mode expires?

Developer Mode lasts around 40 days. Simply open the Developer Mode app on the TV once a month and click EXTEND.

Does it speak my language?

English, Portuguese, Spanish, German and Russian, automatically following the TV's language.

Does it collect any data?

No accounts, no telemetry, no tracking. Requests only go to TMDB (recommendations) and Open-Meteo (local weather forecast).

Is it free?

Yes, completely open-source under the MIT license.
